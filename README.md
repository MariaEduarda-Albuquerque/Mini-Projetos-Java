# Mini-Projetos Java

Repositório de exercícios e mini-projetos desenvolvidos em Java durante meus estudos, organizados por tema para facilitar navegação, prática e revisão.


## Sobre o repositório

Este repositório reúne exercícios práticos em Java, separados por tema, com foco em:

- Praticar lógica de programação
- Fixar conceitos fundamentais da linguagem
- Manter um portfólio organizado de estudo e evolução

---

## Estrutura do Repositório

| Pasta | Conteúdo |
|---|---|
| `Exercícios If Else/` | Exercícios usando estruturas condicionais simples |
| `Exercícios Switch Case/` | Programas utilizando a estrutura `switch` |
| `Exercícios Vetor/` | Atividades com vetores (arrays): média, soma e manipulação de valores |
| `Exercícios While/` | Laços de repetição usando `while` |
| `Exercícios Do, While e For/` | Exercícios com os três tipos de loops |
| `Exercícios de Lógica/` | Desafios de lógica de programação com diferentes níveis de dificuldade |

---

## Como executar os programas

**Pré-requisito:** JDK 17 ou superior instalado.

```bash
# 1. Clone o repositório
git clone https://github.com/MariaEduarda-Albuquerque/Mini-Projetos-Java.git

# 2. Acesse a pasta do exercício desejado
cd "Exercícios Vetor"

# 3. Compile o arquivo
javac NomeDoArquivo.java

# 4. Execute
java NomeDoArquivo
```
